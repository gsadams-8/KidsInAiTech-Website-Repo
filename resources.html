Key AI Terminology

Algorithm
A step-by-step set of rules or instructions given to a computer to solve a problem.
Machine Learning
A branch of AI where computer systems learn from data patterns rather than explicit programming.
Neural Network
A network inspired by the human brain designed to recognize complex patterns in data.
